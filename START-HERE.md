# Start here — your Space Apps project

**This is the project:** the website, its working calculations, the NASA/JPL data files, and the source code. It is not just a demo video.

## What is ready

- The app compares two lunar sites across 1, 3, or 7 days.
- Its seven-day Sun/Earth data and LOLA terrain profiles are included and work offline.
- The project ZIP contains the full folder and source data.
- `SUBMISSION-PACKAGE.md` contains project text you can copy into the Space Apps form.

## Open it in Chrome

Double-click `index.html`. If Chrome is already showing the blank page, press **Ctrl+R** to load the fixed app.

## Push it to GitHub and deploy it to Vercel

Follow [PUBLISH.md](PUBLISH.md). The app is ready as a static website; it needs no API key or server.

## Submit it to Space Apps

1. Open the [NASA Space Apps 2026 site](https://www.spaceappschallenge.org/2026/) and sign in to your registered team.
2. Open the team’s **Project** page and choose the **Lunar Landing Site Navigator** challenge.
3. Copy the prepared answers from `SUBMISSION-PACKAGE.md` into the matching form fields.
4. Add your public Vercel website link and public GitHub source link if the form asks for them.
5. Review the project page and submit it before the deadline.

**Deadline:** November 15, 2026, 11:59 p.m. in your registered event’s local time. [The official event page](https://www.spaceappschallenge.org/2026/) lists this deadline.

The project folder and ZIP contain the complete app, data, and source files. The website link becomes public after you complete the Vercel deployment.
